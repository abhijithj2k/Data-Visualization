# Data Visualisation with Tableau

Two Tableau workbooks built for data visualisation coursework at the University of Technology Sydney.
Open the `.twbx` files in Tableau Desktop or Tableau Public; each has its data packaged inside.

## Australian Open champions

`australian_open_champions.twbx` (data: `australian_open_champions.xlsx`)

Worksheets on champion and runner-up nationalities, champion seed against match duration and win rate,
top-player win rates and title distribution.

## Export and import trends

`export_import_trends.twbx` (data: `export_import_trends.xlsx`)

A story dashboard on export and import trends by commodity category from 1988 onwards, focused on chemical
materials and products, with category contributions over time and a 2025-2029 export forecast.
